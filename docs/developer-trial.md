# 开发者试用任务与反馈记录

状态：试用材料已准备；尚未邀请用户或形成真实试用结论。

## 任务

1. 按 README 运行零密钥案例，记录环境、开始与首次成功时间、遇到的错误及求助次数。
2. 阅读报告，说明候选位置、覆盖范围以及当前可以和暂不能判断的事项。
3. 运行独立确认与修订比较；说明确认样本与探索样本的区别，解释修订结果的适用范围。
4. 将问题包交给另一位参与者，在其环境复算；记录缺失信息和核验结果。

## 成功与观察

首次接入成功率以尝试该任务的参与者为分母；复算成功率以实际交接的问题包为分母；超时、放弃和求助均保留记录。报告理解以参与者能否准确说明证据边界判断。小样本用于发现问题，暂不外推到开发者总体。

每条反馈记录：匿名参与者编号、任务、观察证据、用户表述、影响、出现次数/分母、当前替代办法、拟改动、验收方式和回归状态。公开问题模板与此结构一致。优先处理无法完成任务、误解结论或无法复算的障碍。
