# Roadmap

Priorities follow reproducible failure handling and developer onboarding. They are proposals, with no delivery dates promised.

| Direction | Acceptance evidence |
|---|---|
| Failure-capable reserved evaluation | Frozen normal/fault cases, nonzero positive denominator, repeated references and untouched final test set |
| External executable adapter | Versioned state contract, isolated restoration, synthetic conformance tests and explicit redaction boundary |
| Recovery-point selection | Compare a predefined selection policy with full scanning under equal budgets |
| English workbench interface | User-selectable language with equivalent controls, error states and evidence meanings |
| Developer trial | Observed first-run and handoff outcomes, consented feedback and documented resulting changes |

Open an issue describing the workflow, current workaround, evidence and desired acceptance criteria. Prioritize blocked tasks and misleading interpretations before expanding integrations.
