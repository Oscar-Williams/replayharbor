# 真实模型复验：第一阶段协议

本阶段使用 DeepSeek `deepseek-flash` 的非思考模式，以 JSON 动作调用固定的 Delta-MFP 合成日历环境。接口为官方 HTTPS `/chat/completions`，模型输出上限 192 tokens，temperature=0.2，无自动重试。

## 状态与证据边界

快照包含完整环境状态与已发生的动作/工具结果。恢复时深拷贝快照，每个续跑重新请求模型。发送给模型的内容限定为任务、工具说明、显式公开上下文和历史动作结果。评价所需 effects、正确计划、故障标签与隐藏时区答案不进入提示词。时区通过正常 clarify 动作获取。

模型调用未使用 seed 控制；诊断器中的 sample_label 仅标记复验任务。不同调用的独立性和模型版本稳定性尚未证明。统计确认模块目前仍以模拟案例为验证范围，本轮真实调用只检验接口和恢复流程。

本项目的 evaluator 适配层按全部期望参数精确匹配上游步骤，减少部分参数匹配造成的假成功。执行器只调用内存中的合成工具，支持动作 schema 校验与工具白名单。

## 预算

一次基线加三次探索续跑，每次最多五步；另设 24 次调用硬上限和 0.10 美元预算。发送前以提示词 UTF-8 字节数加 1024 格式余量估算输入 token 上界，并预留最大输出费用。该办法是保守估算，非官方 tokenizer 的形式保证；实际 usage 超过预留时停止后续请求。请求失败或用量不明时保留预留，不隐去可能产生的费用。

费率采用 2026-09-28 官方 Flash 峰值未命中缓存价格：输入 $0.30/百万 tokens，输出 $1.20/百万 tokens。实际缓存与时段折扣可能使账单更低。[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)

## 两轮契约

- original-v1：原始自然语言任务描述，没有明确年份及日期格式。模型产生 `May 9`，精确评价要求 ISO 日期，导致任务未通过。
- explicit-date-v2：公开补充 requested_date=`2026-05-09`、date_format=`YYYY-MM-DD`、time_format=`HH:MM`，保留时区为待澄清字段。该版本改变了公开任务契约，前后对照用于接入问题回归，不作为模型性能提升实验。

首轮发现与修改理由全部保留。后续应对固定任务契约开展失败对照、保留任务和参考结果稳定性实验；工具契约及 evaluator 本身也需要持续验证。
