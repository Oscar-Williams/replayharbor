# 首轮负面结果与下一步实验

本轮固定运行 25 个上游脚本任务、3 个预算、3 种策略，共 225 次诊断。每项诊断包含多次前缀复验。该集合用于工程冒烟检查，使用共同 trace seed 和复验 seed 规则，任务之间存在共享机制与随机数相关性。

48 次预算下，自适应策略与有限样本参考的候选位置一致数为 0/25。检查首个任务发现：前缀 0 获得 22 次采样，17 次失败，估计失败率 0.773；其余前缀失败率为 1，增量约 0.227，低于 delta=0.3，因此输出无候选。均匀策略同预算只给前缀 0 分配 10 次采样，7 次失败，其增量恰好达到阈值。这里存在样本波动、预算分配与阈值共同作用；当前数据不足以确定哪一种策略更接近总体值。

这项观察支持两个产品决策：界面持续呈现“证据不足”，并将独立确认置于 P1 的首项；保留均匀策略供用户选择。所有原始结果保存在 `runs.json`，没有根据此测试集调整策略后覆盖结果。

下一轮先在开发任务上分析多个 seed 和前缀 0 的不确定性传播，再冻结策略与确认样本数，按任务模板分组评测。参考结果也应重复运行。正式比较需要单列无候选、参考不确定和正常案例；当前 25/25 一致率并不构成准确率或泛化收益。
