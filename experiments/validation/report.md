# 独立确认与修订比较：本机验证

日期：2026-09-28。对象：`calendar_missing_timezone`，原始轨迹 seed=1。数据为上游脚本化模拟，本轮无真实模型推理。

## 配置与结果

- 探索：24 次复验，候选前缀为 1。
- 独立确认：每个前缀 512 次，总计 1024 次；新种子与探索阶段分离；alpha=0.05，两个比例的联合 Hoeffding 界。
- 候选失败概率增量区间约为 [0.311, 0.507]；在固定案例和独立抽样假设下支持该候选判据。
- 修订比较：调用者指定上游 `clarify` 干预，固定前缀 1，128 对同 seed 复验，共 256 次调用。
- 模拟失败率从 1.0 变为 0.0；配对失败率降低区间约为 [0.760, 1.000]。
- 总计 1304 次脚本复验；32 项项目测试通过；扩展问题包及旧版问题包均复算通过。

数据见 `../../examples/confirmed-case/report.json`，可读报告见同目录 `index.html`，协议见 `../../docs/statistical-protocol.md`。测试日志与复算日志保留在本目录。

## 解释与产品决定

本轮证实新增工作流能区分探索、独立确认及配对修订评价，并把每个阶段的证据交给他人复算。支持候选的结论保留固定案例与抽样假设；最早前缀和根因仍未确认。模拟干预来自上游，尚无自动代码修复或生产效果结论。

保留上一轮 48 次预算下的负面结果，新增确认阶段作为用户可选择的下一步。预算不足时进行预检，返回所需预算；执行错误后保留已有样本并停止推断。后续需要保留任务模板评测、多个 reference seeds、真实模型和外部试用。
